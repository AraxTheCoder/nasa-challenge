## Goal
Found by probing the Live API with edge-case input (2026-11-15). Both answer a clear 4xx / an empty result instead
of 500:
1. `GET /api/targets/<id>/photometry?ra=0&dec=0` on a field far away: `measure_cutout_many` calls astropy's
   `all_world2pix`, which raises (no convergence / no TAN solution) for a point far from the image.
2. `GET /api/targets/<id>/chemistry?feature=pah&z=inf`: `z_of` rounds before it checks the range
   (OverflowError). Mine from T109.

## Findings
- Probe (2026-11-15): 28 edge-case URLs against the running Live API (bad / out-of-range RA, Dec, size, detector,

  `missing`; the field centre still 40 measured.
