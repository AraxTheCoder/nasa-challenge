# T127: Chemistry presets for objects (brown dwarfs, young stars, Miras, protostars, galaxies, quasars)

- **Owner:** Mati  ·  **Status:** doing
- **Branch:** `mati/T127-object-presets`
- **Depends on / feeds:** T93, T96, T107, T108, T109, T121

## Goal
The Chemistry list offers presets for kinds of objects next to the T107 presets for kinds of places, each tried
on a real field and kept only if it shows something there. Objects from the official text ("brown dwarfs,
quasars, comets, asteroids, stars, supernovae and galaxies"; "rich in hydrogen, water, carbon dioxide, carbon
monoxide") and the official test targets. Visualization only (Decision 2026-11-14): nothing is classified.

## Plan (list agreed with Mati 2026-11-15)
- [ ] Brown dwarfs: H₂O 1.4 + H₂O 1.9 + CH₄ 3.3 (absorption); Eps Ind B, WISE 0855. CH₄ needs its own feature
      (the PAH / CH₄ map is drawn as emission in pictures)
- [ ] Young stars still growing (T Tauri): hydrogen lines at the star; RW Aur
- [ ] Pulsating cool giants (Miras): H₂O 1.4 + H₂O 1.9 + CO (absorption), CO 2.3 µm band head as a new feature; R Dra
- [ ] Protostars inside ice clouds: ices toward embedded stars; ρ Oph
- [ ] Star-forming galaxies: PAH + Br-α + Pa-β at the galaxy's redshift; NGC 6240
- [ ] Quasars: Hα / Pa-β / Pa-α at the quasar's redshift (new features Hα, Pa-α); 3C 273
- [ ] Presets grouped "Objects" / "Places" in the list; a clicked preset keeps its name even if another has the
      same features
- [ ] Not possible with median maps (noted in the list): comets (move between exposures), asteroids, supernovae
